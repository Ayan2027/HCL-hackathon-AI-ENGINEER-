## Known limitations

- Relevance uses keyword/category matching against catalogue fields, a strict automatic proxy for human judgement.
- Latency in mock mode excludes LLM time; rerun with `MOCK_LLM=false` for realistic numbers.
- The eval set was written by the same team that built the engine, so it can be optimistic. Earlier runs exposed real bugs (a gaming phone shown for 'laptop for gaming'; 'Mujhe kuch chahiye' not treated as vague), which were fixed in the engine, not by editing questions.
- Known weak spots in mock/keyword mode, seen in unscripted tests: place names ("going to Kedarkantha") and age-based gifts ("gift for a 10 year old") need the LLM and embeddings to be understood.
